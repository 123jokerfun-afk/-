Дээрх холбоосыг утсаараа нээгээд, дэлгэц дээрээ суулгачихвал **интернэтгүй ч ажиллана**.

<details>
<summary><b>Утсанд суулгах заавар</b></summary>

**iPhone (Safari)**
1. Холбоосыг **Safari**-гаар нээнэ
2. Доод талын **Хуваалцах** товч (⬆️) дарна
3. **"Add to Home Screen" / "Нүүр дэлгэцэд нэмэх"** сонгоно
4. **Add** дарна

**Android (Chrome)**
1. Холбоосыг **Chrome**-оор нээнэ
2. Баруун дээд булангийн **⋮** цэс дарна
3. **"Install app" / "Add to Home screen"** сонгоно

Суулгасны дараа энгийн апп шиг дүрсээр нь нээгдэнэ.
</details>

## Юу хийдэг вэ

| Хэсэг | Тайлбар |
|---|---|
| **Эрсдэлийн үнэлгээ** | 10 шалгуур × 10 пикет → 50 онооны үнэлгээ (Маш бага → Маш их) |
| **Шон тоолох судалгаа** | Шинэ / Хуучин / Модон / Тэнцэхгүй шонг пикет тус бүрээр тоолно |
| **Авто бөглөлт** | Шонгийн судалгаанаас **шалгуур 2, 3**-ыг автоматаар бодож бөглөнө |
| **Excel экспорт** | Бүртгэл болон шалгуур 2,3-ыг `.xlsx` болгож татна |
| **Firebase sync** | Интернэт байхад өгөгдөл автоматаар үүл рүү хадгалагдана |

### Эрсдэлийн түвшин

## Офлайн ажиллагаа

Талбай дээр сүлжээгүй байх нь элбэг тул апп бүрэн офлайн ажиллахаар хийгдсэн:

- Бүх код, Excel номын сан **нэг файл дотор** шингэсэн (гадны CDN шаардахгүй)
- `sw.js` service worker хуудсыг кэшлэнэ
- Өгөгдөл утасны `localStorage`-д хадгалагдана
- Интернэт холбогдоход Firebase рүү автоматаар sync хийнэ

## Менежерийн горим
