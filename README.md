## 🔑 Нэвтрэлт

Апп **2 хаягтай**. Нэвтрэх дэлгэц дээр бүтэн шуудангийн хаяг бичихгүй — зөвхөн
**хэн болохоо сонгоод нууц үгээ** оруулна.

| Сонголт | Дотоод хаяг | Юу хийдэг |
|---|---|---|
| 🔧 **ПД-6 ажилтан** | `ajiltan@toronhashaa.mn` | Бүртгэл хийж үүл рүү илгээнэ |
| 👔 **Админ** | `admin@toronhashaa.mn` | Бүх ажилтны өгөгдлийг цуглуулж нэгтгэнэ |

### Ажилтны нэр — давхардлыг онлайнаар хянана

Ажилтны хаяг нийтлэг тул нэвтэрсний дараа **өөрийн нэрээ заавал эзэмшинэ**.
Нэр бичих үед онлайнаар шалгаж, аль хэдийн эзэмшигдсэн бол оруулахыг зөвшөөрөхгүй.
Нэг нэрийг зөвхөн нэг төхөөрөмж ашиглана.

### Офлайн ажиллагаа

Firebase-ийн SDK интернэтээр ачаалагддаг тул **анх удаа нэвтрэхэд интернэт
шаардлагатай**. Нэг удаа амжилттай нэвтэрсний дараа сесс утсанд хадгалагдах тул
**сүлжээгүй талбай дээр нэвтрэлтгүйгээр үргэлжлүүлэн ажиллана** (толгойд
`ОФЛАЙН` тэмдэг гарна). Интернэт холбогдмогц өгөгдөл автоматаар илгээгдэнэ.

### Хаягуудыг үүсгэх (нэг удаа)

Firebase Console → **Authentication** → **Sign-in method** → **Email/Password**
идэвхжүүлээд, **Users** таб дээр 2 хэрэглэгч нэмнэ:

```
admin@toronhashaa.mn      ← админы нууц үг
ajiltan@toronhashaa.mn    ← ажилтны нууц үг (бүх ажилтанд нийтлэг)
```

⚠️ Ажилтны нууц үг бүх ажилтанд нийтлэг тул хэн нэгэн ажлаас гарвал
**нууц үгийг солиод** бусдад шинэ нууц үгээ мэдэгдэх шаардлагатай.

## 🔐 Firebase Security Rules

Өгөгдөл хэр хамгаалагдсаныг Firebase-ийн **Rules** шийднэ. Дүрэм тавиагүй бол
`databaseURL`-ийг мэдсэн хэн ч бүх өгөгдлийг **уншиж, устгаж** чадна.

`firebase-rules.json` файлд бэлэн дүрэм байгаа. Тавих:

**Firebase Console → Realtime Database → Rules** → агуулгыг буулгаад **Publish**

Тэр дүрэм юу хийдэг вэ:

| Хамгаалалт | Тайлбар |
|---|---|
| Үндэс түгжээтэй | `/` болон `/surveys` дээр шууд бичих боломжгүй → бүх өгөгдлийг нэг дор устгах арга хаагдана |
| Устгал хориотой | `newData.exists()` → төхөөрөмжийн зангилааг хоосруулж болохгүй |
| Хуучин цагаар дарж бичих хориотой | Шинэ `updatedAt` нь хуучнаас багагүй байх ёстой |
| Бүтэц шалгана | Танихгүй талбар бичихийг хориглоно, нэрийн урт хязгаартай |

| Уншилт хаалттай | Бүх өгөгдлийг зөвхөн **админы хаяг** уншина |
| Нэр эзэмшил | `names/` дээрх бичилтийг эзэмшигч төхөөрөмж л өөрчилнө → давхардлыг **сервер тал дээр** атомаар шалгана |

⚠️ Дүрмийг тавихаас **өмнө** дээрх 2 хаягийг үүсгэсэн байх ёстой. Эс бөгөөс
нэвтрээгүй тул хэн ч бичиж чадахгүй болно.
